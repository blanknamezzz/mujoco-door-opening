训练后独立审计只读取训练／验证输入：`standard` 和 `retention` 均为训练 71/72、验证 35/36；净回报分别为训练 0.57995／0.58239、验证均 0.58755。训练、验证、测试分别有 18／9／18 组、72／36／72 个场景，组身份和几何身份跨划分没有重叠。这个差距没有显示明显的开发集过拟合，但测试尚未读取，且验证集在多轮开发中反复使用。
